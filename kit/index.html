Skills

Step-by-step know-how the AI picks up when the task matches. Written once in the core, used in every project.

Hooks

Small scripts that run at fixed moments while the AI works. They steer it without anyone having to remember.

When a session starts

Set up, then kickoff

Fetches the shared core, installs the app and starts a local preview. In a new project the AI asks the kickoff questions before anything else. Otherwise it gets the brief, so nobody explains it again.

Before the AI edits a file

Brief first

The pages stay locked until the brief is written. The shared core can never be edited from a project.

After the AI edits a file

Check and fix

The checks run straight away. If one blocks, the AI gets the reason back and fixes the cause itself.

Checks

The same plain scripts run on commit, after the AI edits, and in CI on every push. Only CI is required. Nothing goes live without it.

See it catch something

What happens if someone, or the AI, tries to commit an API key, a real personal identity number and a hand-made button.
